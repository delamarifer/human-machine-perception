The network learns a field that changes with time

Much noise (t = 1): the arrows point to the middle of the data
Little noise (t = 0.05): the arrows point to the spiral itself
So the network also takes the time as input
f(x, t)
This field is the score: it points toward more likely, less noisy data
Computed exactly on the toy spiral; arrow lengths compressed for display; t = step / 100. Toy example after Welch Labs for 3Blue1Brown (2025)
