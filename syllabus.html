Visual Perception

Instructors: Fernanda De La Torre and Shreya Pandit

Course overview

This is a three-week, hands-on studio course in computer vision. Students explore how machines process and understand visual information, progressing from raw pixels and classical image processing to learned representations and modern vision models.

The course emphasizes practical applications and experimentation. Students will build working vision systems, explore how models represent and interpret images, and critically evaluate their capabilities and limitations.

Format

  • Duration: 3 weeks (15 sessions)
  • Schedule: 2 hours per day
  • Format: lectures, discussions, and in-class coding labs
  • Platform: Google Colab
  • Assessment: in-class labs, homework assignments, and a final project

Week 1. Understanding images

Goal: understand how images encode visual information and how we can extract meaningful structure from pixels.

Topics:

  • Images as data: pixels, color, channels, and perception
  • Image processing: filtering, edges, and transformations
  • Image geometry and feature detection
  • Feature matching and image alignment
  • Classical computer vision applications

Learning outcomes:

  • Load, manipulate, and transform images using Python
  • Apply image processing techniques to extract visual structure
  • Detect and match features across images
  • Build simple computer vision applications

Week 2. Learning visual representations

Goal: understand how machine learning models learn meaningful representations of images.

  • Convolutional neural networks
  • Feature extraction and transfer learning
  • Visual embeddings and similarity
  • Image classification and retrieval
  • Vision-language models, such as CLIP

Learning outcomes:

  • Use pretrained models for image classification
  • Understand how neural networks represent visual information
  • Compare images using learned embeddings
  • Build visual search and zero-shot classification systems

Week 3. Building vision systems

Goal: combine modern vision models into applications that perceive, interpret, and generate visual information.

  • Foundation vision models
  • Object detection and segmentation
  • Multimodal vision-language systems
  • Image generation and diffusion models
  • Evaluating vision systems: capabilities, limitations, and failure modes

Learning outcomes:

  • Apply modern vision models to real-world problems
  • Combine models into end-to-end vision pipelines
  • Build applications involving image understanding, retrieval, or generation
  • Evaluate model performance and identify limitations

Final project

Students design and build an original computer vision application using concepts and techniques from the course.

Possible directions include:

  • Visual search or an image memory system
  • Image generation or a creative exploration tool
  • A multimodal assistant for image understanding
  • Object detection or segmentation
  • A domain-specific computer vision application
  • An exploration of human perception, ambiguity, or hallucination in vision models

Students present their projects and discuss their design decisions, results, and limitations.

Learning approach

The course combines lectures and discussions with hands-on experimentation. Each session introduces new concepts and gives students opportunities to apply them through guided coding labs. Homework assignments reinforce learning and extend lab activities.

Students are encouraged to experiment, ask questions, explore their own interests, and critically evaluate how computer vision systems work and where they fail.
