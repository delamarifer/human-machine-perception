Five object recognition tasks on the same image

1. Image Classification
y = "person" (p = 0.91)
What is in the image? Single category label (or top-k probabilities) for the entire frame.
2. Object Localization
y = ("person", [x, y, w, h])
Where is the main object? Single class label plus one axis-aligned bounding box.
3. Object Detection
{("person", b₁), ("person", b₂), ("car", b₃)}
What objects are present & where? Variable-length list of classes, boxes, and confidences.
4. Semantic Segmentation
M ∈ {sky, road, person, car}^(H×W)
Which category owns each pixel? Dense pixel map; two people share the same class label.
5. Instance Segmentation
{mask₁: person#1, mask₂: person#2, mask₃: car#1}
Which pixels belong to each individual object? Separates overlapping instances.
