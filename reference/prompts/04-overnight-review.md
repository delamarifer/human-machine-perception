# Prompt 4: the overnight whole-talk pass

Paste to the coordinator before going to bed, a few days before the talk.

---

Overnight, make the whole presentation better, and push so that in the morning I can practice.

1. Spawn one review agent. It reads <the paper(s), current drafts> and the full transcript (every
   slide's notes in order, from the final deck), and writes `review/<date>-overnight-review.md`:
   concrete fixes per slide for intuition (would a smart non-specialist follow this?), rhythm
   (one idea per click, no slide that drags), accuracy (every claim and number checked against
   the paper; quote the paper's sentence), and timing (word count at 140 wpm per section).
2. Check every factual fix against the paper yourself before routing it. Reviewers overclaim.
3. Route the fixes to the owning sessions, as many as you can tonight. Do NOT change my own
   wording or the strength of any scientific claim: queue those as numbered questions for me.
4. Push what's done, walk the final deck (every click, forward and back, no errors, no 404s,
   notes match clicks), and commit.
5. Write `review/MORNING-<date>.md`: the link to practice from; what changed (by slide); what's
   not done; the decisions that need me, as a numbered list I can answer in one message; the
   estimated talk length; the git commit to restore if anything is wrong.
