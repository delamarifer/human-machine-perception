# Notebooks

Hands-on Google Colab labs for the course, one or more per day. Students open them from the course
page (`index.html`) with the "Open in Colab" badge; nothing to install.

| Notebook | Day | Topic |
|---|---|---|
| [day01-lab-simple-vision-system.ipynb](day01-lab-simple-vision-system.ipynb) | 1 | Lab: a simple vision system that recovers 3D from one image of a blocks world (after Ch. 2 of Torralba, Isola & Freeman, *Foundations of Computer Vision*) |
| [day01-practice-numpy-images.ipynb](day01-practice-numpy-images.ipynb) | 1 | Optional practice: images as NumPy arrays; measuring the checker-shadow illusion |
| [day02-lab.ipynb](day02-lab.ipynb) | 2 | Day 2 lab: one photograph through a center crop, ResNet-18, a depth map, and a small upload app |

## Conventions (every notebook)

**Name.** `dayNN-<kind>-<topic>.ipynb`, lowercase with hyphens: `day01-lab-simple-vision-system.ipynb`,
`day03-pset-edges.ipynb`, `day02-practice-numpy.ipynb`. `<kind>` is `lab` (done in class), `pset`
(problem set) or `practice` (optional).

**Self-contained.** It runs top to bottom on a fresh Colab runtime (*Runtime → Run all*) with no
errors and no edits:
- only packages that are preinstalled in Colab or pip-installable (`!pip install -q <pkg>` in the setup
  cell, pinned if the version matters);
- it downloads its own data from stable public URLs (or makes it, like the Day 1 lab's rendered box world): files in this repo through
  `https://raw.githubusercontent.com/delamarifer/human-machine-perception/main/<path>`, or a
  well-known dataset host. No Google Drive mounts, no local paths, no API keys;
- the data a notebook uses must be on `main` before the notebook is announced, or its URL is a 404.

**Badge.** The first cell is the badge, then the title:

```markdown
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/delamarifer/human-machine-perception/blob/main/notebooks/<file>)
```

**Shape.**
1. Title, then **learning goals** ("By the end you will be able to ...") and a short "how to use this
   notebook".
2. Section 0, an **environment check**: imports and versions; if it runs, the student is ready.
3. Numbered sections: a short explanation (a few sentences, plain words, students may be new to
   Python), then a small example cell they run and change.
4. **"Your turn"** exercises. Each exercise cell runs without errors when left blank (variables start
   as `None`, and the cell only plots or prints once they are filled in). When later cells need the
   result, a blank exercise falls back on the course's answer and prints that it did. Its solution sits right below
   in a collapsed `<details>` block ("Show a solution"). A problem set that is graded keeps its
   solutions in a separate file that is not in this public repo instead.
5. "What you learned" and the homework, to close.

**Honest content.** Never invent data, figures or citations. Credit every image and dataset. Any
pixel coordinates the text uses are measured from the image with code, never by eye.

**Saved with outputs cleared**, so the diff stays small and students see their own results.

## How a notebook is made

Each notebook is generated by a small script in `build/` (`build/day01_lab.py`), which holds the
cells, and each exercise's solution, as plain text. `build/nbtools.py` has the shared pieces
(`md`, `code`, `hidden` for folded helper code, `turn` for an exercise plus its solution). Edit the
script, not the `.ipynb`, then rebuild:

```bash
python3 notebooks/build/day01_lab.py
```

(needs `pip install nbformat`). Editing the notebook in Colab or Jupyter is fine for a quick fix;
then copy the change back into the script so the next rebuild keeps it.

## Checking a notebook

Run it blank and with every solution filled in; both must finish with no errors:

```bash
pip install numpy scipy matplotlib pillow nbformat nbconvert ipykernel
python3 notebooks/build/day01_lab.py --solved /tmp/solved.ipynb
jupyter nbconvert --to notebook --execute notebooks/day01-lab-simple-vision-system.ipynb --output /tmp/blank-run.ipynb
jupyter nbconvert --to notebook --execute /tmp/solved.ipynb --output /tmp/solved-run.ipynb
```

Then open it once in Colab from the badge (after it is on `main`) and *Run all*.
