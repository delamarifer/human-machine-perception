# Notebooks

Hands-on Google Colab labs for the course, one or more per day. Students open them from the course
page (`index.html`) with the "Open in Colab" badge; nothing to install.

| Notebook | Day | Topic |
|---|---|---|
| [day01-practice-numpy-images.ipynb](day01-practice-numpy-images.ipynb) | Class day 2 | Checker-shadow image and NumPy: pixels, slices, brightness, contrast |
| [day01-lab-simple-vision-system.ipynb](day01-lab-simple-vision-system.ipynb) | Class day 2 | A simple vision system that recovers 3D from one image of a blocks world (after Ch. 2 of Torralba, Isola & Freeman, *Foundations of Computer Vision*) |
| [day02-lab.ipynb](day02-lab.ipynb) | Class day 3 | ResNet-18 on the café photo, the Rubik's cube, and the elephant statue, plus an optional depth section |
| [day03-lab.ipynb](day03-lab.ipynb) | Class day 4 | Day 3 lab: Part 1 metamers, then Part 2 image filtering. |
| [day03-lab-metamers.ipynb](day03-lab-metamers.ipynb) | Class day 4 | Make metamers with plenoptic: a pooling model by hand, front-end and texture models, ResNet-18 early vs late, and sound (a cochleagram model, sound-texture statistics, wav2vec 2.0). Data in `data/day03/` |
| [day03-lab2-image-filtering.ipynb](day03-lab2-image-filtering.ipynb) | Class day 4 | Lab 2, image filtering: filter your own photograph and make a printable trifold name tag. Student notebook; no solutions. |

## Conventions (every notebook)

**Name.** `dayNN-<kind>-<topic>.ipynb`, lowercase with hyphens: `day01-lab-simple-vision-system.ipynb`,
`day03-pset-edges.ipynb`, `day02-practice-numpy.ipynb`. `<kind>` is `lab` (done in class), `pset`
(problem set) or `practice` (optional).

**Self-contained.** It runs top to bottom on a fresh Colab runtime (*Runtime → Run all*) with no
errors and no edits:
- only packages that are preinstalled in Colab or pip-installable (`!pip install -q <pkg>` in the setup
  cell, pinned if the version matters);
- it downloads its own data from stable public URLs (or makes it, like the Day 1 lab's rendered box world): files in this repo through
  `https://raw.githubusercontent.com/delamarifer/human-machine-perception/main/<path>`, or a
  well-known dataset host. No Google Drive mounts, no local paths, no API keys;
- the data a notebook uses must be on `main` before the notebook is announced, or its URL is a 404.

**Badge.** The first cell is the badge, then the title:

```markdown
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/delamarifer/human-machine-perception/blob/main/notebooks/<file>)
```

**Shape.**
1. Title, then **learning goals** ("By the end you will be able to ...") and a short "how to use this
   notebook".
2. Section 0, an **environment check**: imports and versions; if it runs, the student is ready.
3. Numbered sections: a short explanation (a few sentences, plain words, students may be new to
   Python), then a small example cell they run and change.
4. **"Your turn"** exercises. Each exercise cell runs without errors when left blank (variables start
   as `None`, and the cell only plots or prints once they are filled in). When later cells need the
   result, a blank exercise falls back on the course's answer and prints that it did; that answer is
   computed by a function in the folded helper cell (`course_edges(gray)`), so the exercise cell
   itself shows no solution.
5. **Two versions.** This repository is public, so the **student notebook** (the committed `.ipynb`,
   opened from the Colab badge) has **no solutions**: no collapsed answers, no solution text in
   outputs or metadata. The **teacher copy** has every solution right below its exercise under a
   "Solution" heading, for going over them in class. It is built into `notebooks/teacher/`, which is
   git-ignored: never commit it. Upload it to your own Google Drive and open it from Colab there.
   The solutions themselves live in `notebooks/build/private/<script>_solutions.py`, also git-ignored:
   without that file a script still builds the student notebook, but `--teacher` and `--solved` stop
   with a message. Keep a copy of the private folder somewhere safe (your Drive).
   Every exercise cell has the fixed id `turn-N` and, in the teacher copy, its solution `solution-N`,
   so a slide can open it directly: `<notebook url>#scrollTo=turn-3` (the Day 2 deck does this).
   Under each exercise, `resources(...)` adds a **Helpful resources** line: the matching section of the
   book and the official docs of the functions it needs. Point to concepts, never to the answer.
6. "What you learned" and the homework, to close.

**Honest content.** Never invent data, figures or citations. Credit every image and dataset. Any
pixel coordinates the text uses are measured from the image with code, never by eye.

**Saved with outputs cleared**, so the diff stays small and students see their own results.

## How a notebook is made

Each notebook is generated by a small script in `build/` (`build/day01_lab.py`), which holds the
cells, and each exercise's solution, as plain text. `build/nbtools.py` has the shared pieces
(`md`, `code`, `hidden` for folded helper code, `turn` for an exercise plus its solution, `answer`
for the answer to a talk-it-over exercise). Edit the script, not the `.ipynb`, then rebuild both
versions:

```bash
python3 notebooks/build/day01_lab.py
```

```bash
python3 notebooks/build/day01_lab.py --teacher
```

The first writes the student notebook; the second writes
`notebooks/teacher/day01-lab-simple-vision-system-teacher.ipynb`. A script opts into the split with
`main(FILE, private_solutions=True)`; without it (`day01_practice.py`, `day02_lab.py` for now) the
student notebook still shows each solution in a collapsed "Show a solution" block.

(needs `pip install nbformat`). Editing the notebook in Colab or Jupyter is fine for a quick fix;
then copy the change back into the script so the next rebuild keeps it.

## Checking a notebook

Run it blank, as the teacher copy, and with every solution filled in; all must finish with no errors.
Then check that no solution text made it into the student file (search it for a line of each solution):

```bash
pip install numpy scipy matplotlib plotly pillow nbformat nbconvert ipykernel
python3 notebooks/build/day01_lab.py --solved /tmp/solved.ipynb
jupyter nbconvert --to notebook --execute notebooks/day01-lab-simple-vision-system.ipynb --output /tmp/blank-run.ipynb
jupyter nbconvert --to notebook --execute /tmp/solved.ipynb --output /tmp/solved-run.ipynb
jupyter nbconvert --to notebook --execute notebooks/teacher/day01-lab-simple-vision-system-teacher.ipynb --output /tmp/teacher-run.ipynb
```

Then open it once in Colab from the badge (after it is on `main`) and *Run all*.
